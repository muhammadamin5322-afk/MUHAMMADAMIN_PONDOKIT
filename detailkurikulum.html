Empat fase, ±48 minggu

Fase 1A · ±2 minggu Cara Berpikir

Tujuan: Membangun computational thinking sebelum menyentuh kode: mengurai requirement dan menulis solusi dalam bahasa manusia yang presisi.

  • Membaca dan mengklarifikasi requirement yang ambigu
  • Dekomposisi masalah besar menjadi sub-masalah kecil
  • Pseudocode dan flowchart sebagai alat berpikir
  • Latihan "eksekusi pseudocode" antar siswa
  • Konteks latihan: skenario software house, tanpa kode

Indikator keberhasilan: Siswa bisa menerima requirement lisan, mengajukan pertanyaan klarifikasi yang tepat, memecah satu fitur jadi 5–7 sub-tugas, dan menulis pseudocode untuk proses bercabang.

Fase 1B · ±4 minggu Orientasi Sistem

Tujuan: Membangun mental model cara kerja aplikasi web sebagai sistem utuh. Project: mini project throwaway, sengaja dibuang setelah selesai.

  • Cara kerja web: request-response, client vs server
  • Node.js sebagai runtime JavaScript
  • Express.js dasar: routing, middleware, REST API
  • PostgreSQL dasar: tabel, relasi, SELECT, INSERT, UPDATE, DELETE, JOIN
  • Kerja tim di satu repository: branching, pull request, code review dasar

Indikator keberhasilan: Siswa bisa menjelaskan alur data dari klik tombol di browser sampai tersimpan di database, dan membuat endpoint API sederhana yang terhubung ke database.

Fase 2 · ±10 minggu Fondasi Project

Tujuan: Memulai project utama dari titik yang paling terkontrol, sambil membiasakan pola belajar pagi-siang.

  • Setup project: struktur folder, environment variables, konvensi tim
  • Schema database: users, roles, clients, projects, teams
  • Migrasi database dan seeding data
  • Autentikasi: login, register, JWT
  • RBAC: developer, project manager, finance, admin, client
  • Dasar React/Next.js: komponen, props, state, routing
  • Modul dibangun: landing page dan onboarding, autentikasi multi-role, Employee & Team Management, Notification & Audit Log

Indikator keberhasilan: Auth bekerja, schema database masuk akal, RBAC berfungsi, dan siswa paham kenapa struktur ini dipilih.

Fase 3 · ±20 minggu Pengembangan Utama

Tujuan: Inti dari program. Siswa mulai mengambil keputusan teknis sendiri; mentor bergeser dari menjelaskan menjadi bertanya dan memandu.

  • Modul Tier 1: CRM (klien, proposal dengan status approval, quotation), Project Management (Kanban, milestone, assignment task), Reporting & Dashboard
  • Modul Tier 2: Time Tracking, Bug Tracking, Invoice & Payment, Leave & Attendance, Client Portal
  • React/Next.js lanjutan: state management, data fetching, optimistic updates
  • Real-time notification dengan WebSocket atau SSE
  • Struktur data praktis dan algorithmic thinking lewat studi kasus fitur kompleks

Indikator keberhasilan: Siswa bisa merancang sendiri pendekatan untuk fitur baru sebelum bertanya ke mentor, dan berdiskusi soal trade-off teknis antar sesama siswa.

Fase 4 · ±12 minggu Penyelesaian dan Refleksi

Tujuan: Dari membuat fitur baru ke membuat sistem yang layak dipakai. Mentor berperan sebagai konsultan: siswa membawa masalah, mentor mengarahkan cara berpikir.

  • Modul Tier 3 (sesuai sisa waktu): File & Asset Management, Requirement & Documentation, Knowledge Base & Wiki, AI features
  • Testing: unit testing dan integration testing dasar
  • Error handling konsisten di seluruh aplikasi
  • Deployment dan dasar CI/CD
  • Code review formal antar siswa, refactoring, dokumentasi project

Indikator keberhasilan: Platform siap dipresentasikan dan di-demo; siswa bisa menjelaskan keputusan arsitektur dan membaca serta memperbaiki kode siswa lain.

Catatan implementasi

Database, struktur data, algoritma

Tidak diberi blok waktu sendiri. Database sejak Fase 1B, struktur data disisipkan di Fase 3, algoritma sebagai cara berpikir sejak Fase 1A.

Tier 3 dan AI features

Tidak dijadwalkan kaku, dikerjakan di Fase 4 sesuai sisa waktu dan kematangan tim. AI sebagai pelengkap, bukan inti.

Fleksibilitas durasi

Estimasi minggu adalah panduan. Fase 1A tidak boleh terburu-buru; perpanjang jika indikator belum tercapai.

Evaluasi

Tiap akhir fase ada checkpoint: sesi refleksi bersama, bukan ujian formal, agar setiap siswa benar-benar memahami hasil kerjanya.
